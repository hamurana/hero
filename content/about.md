This site is built with [Hugo](https://gohugo.io/) and the
[Blowfish](https://blowfish.page/) theme, and deployed to GitHub Pages.

Front matter on any page (like `showDate: false` above) overrides the
site-wide defaults from `config/_default/params.toml` for that page only.
